# Before It Strikes - Badminton Tournament

A high-end, interactive landing page for the "Before It Strikes" initiative. This project promotes physical health and stroke prevention awareness through a Badminton Tournament, featuring a premium digital experience.

## ✨ Features

- **Premium Visual Design**: Dark mode aesthetic with profound royal blue and vibrant lime green accents.
- **Advanced Animations**: Powered by Framer Motion, utilizing spring-physics choreography, reveal animations, and micro-interactions.
- **Architectural UI**: Features modern "Double-Bezel" containers and a bento-grid layout for a highly structured, expensive feel.
- **Responsive Navigation**: Sticky header with glassmorphism effects and smooth scrolling.
- **Modern Tech Stack**: Built with Next.js (App Router), React, Tailwind CSS, and Framer Motion.
- **Interactive Elements**: Includes custom SVG graphics, dynamic statistics, and visually rich interactive cards.

## 🚀 Getting Started

The main application is located in the `app-next` directory.

### Prerequisites

Ensure you have Node.js and `npm` installed.

### Installation

```bash
cd app-next
npm install
```

### Running the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Technologies Used

## 🎨 Design Philosophy
This project ignores generic default aesthetics and instead uses the `design-taste-frontend` principles for a tailored, metric-based visual balance that leverages hardware acceleration, sophisticated typography (Nunito), and strict architectural layouts.
